# 🛒 Local Price Scanner

FastAPI-застосунок для порівняння цін товарів у локальних торгових мережах. Збирає дані через веб-скрапінг, використовує Gemini AI для розумного ранжування результатів за релевантністю.

**🔗 Живе демо:** https://local-price-scanner-production.up.railway.app/app

## Можливості

- 🔍 Пошук товару одночасно в кількох торгових мережах (Аврора, Копійочка)
- 🤖 AI-фільтрація результатів через Gemini — показує найрелевантніші збіги, а не сирий список
- ⚡ Кешування результатів у PostgreSQL (30 хв) — миттєва відповідь на повторні запити
- 🌐 Простий веб-інтерфейс для пошуку

## Стек технологій

- **Backend:** FastAPI, Python 3.13
- **База даних:** PostgreSQL (psycopg2)
- **Скрапінг:** requests, BeautifulSoup4
- **AI:** Google Gemini (gemini-2.5-flash)
- **Деплой:** Railway, Git/GitHub
